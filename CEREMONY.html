09WEDDING CEREMONY

婚禮儀式指南

文定、迎娶與拍攝準備，
把心力留給當天最重要的人。

各地習俗與家庭安排不同，儀式、用品及紅包金額請先與雙方家人、媒人與婚禮團隊確認。

一、文定儀式：詳細準備物

男方準備 (下聘)

1. 六禮/十二禮包含西裝、皮鞋、金飾、喜餅、炮燭禮、聘金。
2. 聘金紅包大聘（撐面子）、小聘（實際收受），需用紅封套。
3. 壓茶甌紅包奉茶結束後，男方親友放入空茶杯之紅包。

女方準備 (回禮)

1. 奉茶用具桂圓紅棗茶（去籽）、圓托盤、6/10/12個茶杯。
2. 儀式座椅一張靠背高椅、一張矮腳踏墊（象徵新娘有靠山）。
3. 回禮禮品男方西裝、皮帶、襪子、及男方帶來禮品之半數回禮。

二、迎娶儀式：關鍵必備清單

車隊與外勤準備

1. 車頭彩/門把花主禮車裝飾車頭彩，其餘車輛綁門把花。
2. 竹子/甘蔗繫於主禮車頂，象徵節節高升、有頭有尾。
3. 鞭炮出發、抵達、回程時使用。

出閣與進門必備

1. 米篩或黑傘遮擋天公，保護新娘（懷孕者必備黑傘）。
2. 扇子二把一把繫紅包丟下，一把攜帶去夫家。
3. 火盆與瓦片進門前跨火盆（去邪）、踩瓦片（弄瓦成徵）。

三、紅包準備與工作人員

項目原指南參考金額 (NTD)準備方
開門禮 (男童)600 - 1,200新郎/新娘
好命婆/媒人禮2,000 - 6,600雙方皆可
奉茶壓茶甌1,200 - 3,600男方親友
闖關/伴娘禮600 - 1,200新郎
司機禮/工作人員1,200 - 2,000雙方

四、當天儀式總覽

文定儀式
奉茶 -> 壓茶甌 -> 掛手指(交換戒指) -> 祭祖 -> 訂婚宴。
* 戒指通常戴中指，不壓到底代表互相尊重。
迎娶闖關
車隊抵達 -> 闖關遊戲 -> 讀愛妻宣言。
* 關卡建議控制在3關內，避免耽誤進房吉時。
拜別父母
感謝養育之恩 -> 蓋頭紗 -> 擁抱。
* 此時是情感最高峰，請記得多準備衛生紙。
擲扇與出閣
上車 -> 擲扇 -> 拾起扇子。
* 新娘上車後不可回頭看，代表不留壞習慣。
過火進房
跨火盆 -> 踩瓦片 -> 坐公婆椅 -> 吃湯圓。
* 入房後新郎新娘同坐長褲墊底的椅子，象徵平起平坐。

影像師的關鍵提醒

  • 光線：儀式進行時請將窗簾拉開，光線充足照片才美。
  • 雜物：新娘房、客廳背景請先清理雜物（如塑膠袋、外帶杯）。
  • 慢動作：戴戒指、蓋頭紗、擁抱，請放慢速度，停留 3 秒讓攝影師捕捉。
  • 情感：不需要刻意看鏡頭，專注在彼此與父母的互動上。
